# Parkinson's Disease Detection using SVM

## 📌 About The Project
This project aims to detect Parkinson's disease using voice measurements. Parkinson's affects voice, and ML can help in early diagnosis.

## 📊 Dataset
- **Source:** UCI Machine Learning Repository - Parkinson's Dataset
- **Total Records:** 195
- **Features:** 22 voice features (MDVP:Fo, Jitter, Shimmer, HNR, NHR, RPDE, DFA etc.)
- **Target:** status (1 - Parkinson's, 0 - Healthy)

## ⚙️ What I Did
1.  Data Exploration using Pandas
2.  Train-Test Split (80% Train, 20% Test)
3.  Model Training using Support Vector Machine (SVM)
4.  Model Evaluation - Accuracy Score, Confusion Matrix

## ✅ Result
**Accuracy: 87.17%**
The SVM model correctly predicts if a person has Parkinson's or not.
